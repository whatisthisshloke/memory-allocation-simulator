# memory-allocation-simulator
A C++ project that simulates contiguous memory allocation in an operating-system environment using Object-Oriented Programming.

## Overview

The simulator allows processes to request memory, get allocated memory blocks, and release memory when they terminate.

It demonstrates how different memory allocation algorithms affect memory utilization and external fragmentation.

## Algorithms

- First Fit
- Best Fit
- Worst Fit
- Next Fit

## Tech Stack

- C++
- Object-Oriented Programming
- Data Structures and Algorithms
- Operating Systems concepts

## Planned Features

- Dynamic memory allocation and deallocation
- Memory block splitting and coalescing
- Memory map visualization in the console
- Memory utilization and fragmentation statistics
- Runtime polymorphism using inheritance and virtual functions
- Comparison of allocation algorithms
